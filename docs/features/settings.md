# Settings

One launcher tile, **Settings**, opening a single **Theme** option.

## Theme

Four themes are available: **Modern Light** (default), **Modern Dark**,
**Console Green**, **Console Red**.

### Using it

1. Open **Settings > Theme**.
2. Tap a theme to apply it. It takes effect immediately across every open
   screen — there's no separate "Apply" or restart step, and no preview;
   tapping a theme *is* applying it.
3. The button for the currently-active theme is shown checked/highlighted
   so you can tell which one is live at a glance.

Your choice is saved and survives a reboot.
